# 자연스러운 한국어 음성

## 사용

**파일 → TTS 음성 생성 → 텍스트·음성·출력**에서 **자연음성 설치**를 누릅니다. 공식 Supertonic 3 모델 약 383MiB를 한 번 내려받습니다. 설치가 끝나면 음성 목록에서 **자연음성 · 여성 F1~F5** 또는 **자연음성 · 남성 M1~M5**를 선택합니다. 설치된 자연음성이 초기 목록에서 우선하며 새로고침 시 현재 선택을 유지합니다. 목소리 번호는 실제 제공된 기본 음색의 식별자입니다.

모델 설치 후에는 인터넷·API 키·GPU 없이 CPU에서 한국어를 합성합니다. TTS 입력 문장은 외부 서버로 전송하지 않습니다. 기존 Windows 설치 음성도 계속 선택할 수 있습니다. 설치하지 않은 자연음성을 선택하면 설치 안내를 표시하고 기존 저장 파일을 보존합니다. 작은 창에서는 입력 탭을 스크롤하여 텍스트·음성·모델 설치·출력 설정에 접근할 수 있습니다.

**원본/변조 미리듣기, Voice FX, WAV 저장, 일회용 출력, 사운드보드 추가**에 모두 같은 음성 선택이 적용됩니다. 자연음성의 원본도 텍스트·선택 음성·읽기 속도·볼륨이 같으면 재사용하므로 효과만 변경할 때 다시 합성하지 않습니다. 처음에는 변조를 끈 원본 음성으로 F1~F5·M1~M5를 비교한 뒤 원하는 목소리를 고르세요.

## 설치·복구·취소

- 설치에만 인터넷이 필요합니다. 공개 모델 저장소의 고정 revision 파일 17개와 크기·SHA-256을 검증하며, 사용자 인증 파일과 SDK 자동 다운로드를 사용하지 않습니다.
- 설치 중 진행률을 표시합니다. **처리 취소 / 정지**로 중단하면 미완료 파일을 정리하고, 재설치 시 검증된 완료 파일은 재사용합니다. 네트워크 연결이 멈춘 경우 현재 읽기 제한 시간(최대 30초) 뒤에 취소가 반영될 수 있습니다.
- 모델 파일이 손상되면 합성을 중단하고 설치·복구 안내를 표시합니다. **자연음성 설치**를 다시 누르면 손상된 파일만 새로 받습니다.
- 원자적 WAV 교체를 사용하여 합성 실패·취소 시 기존 출력 파일을 보존합니다. 생성 중 화면을 닫아도 취소를 전달합니다.
- 모델 로드와 ONNX 추론은 네이티브 단계가 반환한 뒤 취소를 확인합니다. 취소가 즉시 완료되지 않을 수 있으며 UI에는 취소 요청 상태를 표시합니다. 음성은 최대 120자 단위로 나누어 청크 사이에서도 취소를 확인합니다.

모델은 기존 사용자 데이터 폴더의 `tts_models/supertonic3-3cadd1ee`에 보관합니다. 소스 실행은 프로젝트 `user_data`, 설치본은 `%LOCALAPPDATA%/seoul2line Toolbox/user_data`를 사용합니다. 두 실행 방식의 데이터 폴더가 다르므로 설치본에서 처음 사용할 때 모델 설치가 다시 필요할 수 있습니다. 앱 업데이트는 모델을 배포 파일로 덮어쓰지 않습니다.

## 품질과 성능

한국어(`ko`)·합성 품질 10단계·44,100Hz 모노 PCM 16비트로 생성합니다. 읽기 속도(-10~10)는 약 0.71~1.41배의 합성 속도에 대응하고, Voice FX의 재생 속도 조절은 별도로 적용합니다. 볼륨(0~100)은 생성 음성에 적용하며 클리핑을 제한합니다. 처리 한도는 기존 Voice FX와 같은 최대 10분 또는 3,200만 샘플입니다. ONNX Runtime의 내부 CPU 스레드를 최대 4개로 제한하고 모든 합성·설치는 작업 스레드에서 실행합니다.

이 PC의 2026-10-29 실측: 약 25자의 한국어 문장을 10종 모두 생성했습니다. 결과는 4.18~5.15초였고, 초기 모델 준비 포함 첫 합성 약 28초, 이후 약 1.9~4.9초가 걸렸습니다. 첫 사용의 모델 로드에는 수십 초가 걸릴 수 있고 PC 사양·부하·문장 길이에 따라 달라집니다. 같은 TTS 도구 안에서는 로드한 모델을 재사용하며 도구 종료 후 다시 열면 준비 시간이 다시 필요합니다.

자동 검사는 신호·길이·오류 처리와 호환성을 확인하며 사람의 청취 품질을 보증하지 않습니다. 음색과 자연스러움은 문장과 목소리마다 다릅니다. 숫자·외래어·긴 문장·혼합 언어의 발음을 확인하고 필요하면 문장을 나누거나 표기를 다듬으세요. 현재 자연음성 선택은 한국어로 연결했으며 타 언어 선택·사용자 음성 복제는 추가하지 않았습니다.

## 구현·의존성

- `app/services/natural_tts.py`: 고정 모델 설치·검증, 여성/남성 10종, 청크별 로컬 합성
- `app/assets/tts/supertonic3-manifest.json`: 공식 모델 revision·파일 크기·해시
- `app/services/tts.py`: 기존 생성·캐시·Voice FX·출력·등록 경로의 엔진 분기
- `app/tools/file_tts.py`: 음성 목록·설치 상태·설치/복구 버튼·작은 창 스크롤
- `app/services/natural_tts_probe.py`: 네트워크 없이 SDK와 ONNX CPU 추론 확인
- `installer/build.ps1`, `app/healthcheck.py`: 네이티브 라이브러리·메타데이터 수집과 동결 실행 검사

공식 Python SDK `supertonic==1.3.1`, CPU `onnxruntime==1.31.1`, 호환용 `huggingface-hub==0.36.0`을 추가했습니다. NumPy·SoundFile은 기존 것을 재사용합니다. 모델 가중치는 설치 프로그램에 포함하지 않고 명시적 설치 버튼으로 받으므로 저장소나 기본 설치 파일에 약 383MiB의 모델을 중복 포함하지 않습니다. 공식 코드와 모델의 설명·라이선스는 [Supertonic 3 모델 안내](https://huggingface.co/Supertone/supertonic-3), [공식 Python SDK](https://pypi.org/project/supertonic/)를 참고하세요. 다운로드한 모델에는 공식 LICENSE 파일도 함께 보관합니다.

## 검증

```powershell
py -m unittest discover -s tests -p "test_natural_tts.py" -v
py -m unittest discover -s tests -p "test_tts.py" -v
py -m unittest discover -s tests -p "test_voice_fx*.py" -v
py -m unittest discover -s tests -p "test_soundboard*.py" -v
powershell -NoProfile -File installer/build.ps1 -Incremental
```

새 자동 검사는 모델 설치·무결성·재사용·취소·네트워크 오류·불일치 파일 보존, 오프라인 합성·음성 수·CPU 제한·한국어·속도·볼륨·긴 문장 분할, 기존 원본 캐시·Voice FX·세 테마·작은 창과 텍스트 보존을 확인합니다. CPU 실행 검사는 SDK 로딩과 작은 ONNX 모델 추론을 사용하므로 검사 자체가 음성 모델을 자동 다운로드하지 않습니다.

실제 로컬 모델 10종의 한국어 파일 생성·자연음성+로봇 FX, 임시 DB 사운드보드 직접 등록·취소 시 기존 파일 보존을 확인했습니다. 직접 청취·실제 출력 장치·다른 PC에서의 모델 다운로드와 실행은 수동 확인 항목입니다.
