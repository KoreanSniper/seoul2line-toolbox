# Sandbox

미니게임 → **Sandbox**에서 여는 간단한 입자 실험실이다. 파우더토이에서 착안한 독립 구현이며, 160×100 셀에서 간소화한 재료 반응을 제공한다. 원작 저장 파일과 호환되지 않는다.

## 조작

| 조작 | 기능 |
| --- | --- |
| 왼쪽 재료 선택 → 좌클릭·드래그 | 빈 공간에 원형 브러시로 배치 |
| 우클릭·드래그 / 지우개 | 입자 제거 |
| 캔버스 위 휠 | 브러시 반경 1~12셀 |
| 가열 / 냉각 | 기존 입자 온도를 브러시 적용당 ±100°C 변경 |
| 입자 위 마우스 | 좌표·재료·온도 표시 |
| 일시정지/계속 / Space | 시뮬레이션 정지·재개 |
| 한 단계 / N | 정지 상태로 한 단계만 계산 |
| 단계 배속 | 화면 갱신당 최대 1·2·4단계 계산. 계산 예산을 넘으면 추가 단계 생략 |
| 예제 | 물·모래·유리 용기 장면으로 교체 |
| 모두 지우기 | 현재 격자 비우기 |
| 저장 / 불러오기 | 현재 장면 단일 슬롯 저장·복원 |

Space·N은 캔버스를 클릭해 포커스를 둔 상태에서만 동작한다. 다른 도구로 전환하거나 화면을 닫으면 타이머를 해제한다. 숨겨진 화면은 진행하지 않는다.

재료 목록 위의 휠은 목록을 스크롤한다. 재료 버튼에 포커스를 둔 뒤 위·아래 방향키로 선택을 옮길 수 있고, 화면 밖의 선택 항목은 자동으로 표시된다.

## 재료와 반응

18종 재료: 모래, 물, 돌, 나무, 기름, 불, 증기, 얼음, 용암, 화약, 연기, 산, 금속, 전기, 식물, 소금, 소금물, 유리.

- 모래·소금·화약은 아래로 쌓이고 액체는 옆으로 퍼진다. 무거운 입자가 액체 아래로 가라앉고, 기름은 물 위에 뜬다. 기체는 위로 이동한다.
- 인접 입자는 열을 교환한다. 가열·냉각 도구로 강제 실험할 수 있으며 온도 범위는 −273~2,000°C이다.
- 물은 100°C 이상에서 증기, 0°C 이하에서 얼음이 된다. 얼음은 0°C 초과에서 물, 증기는 95°C 미만에서 물이 된다.
- 나무·기름·식물은 불·용암·전기에 닿거나 300°C 이상이면 탄다. 물·얼음은 불을 끄고, 불은 시간이 지나면 연기가 되어 사라진다.
- 용암과 물·소금물·얼음이 닿으면 돌과 증기가 된다. 650°C 미만의 용암은 돌로 굳는다. 모래를 1,400°C 이상으로 가열하면 유리가 된다.
- 화약은 불·용암·전기에 닿거나 250°C 이상이면 반경 5셀에 반응한다. 주변 화약은 다음 단계에서 연쇄 반응하고 금속·유리는 열을 받으며 유지된다.
- 전기를 금속에 칠하면 금속 경로로 순간 전도가 전달된 후 금속으로 돌아온다.
- 산은 인접한 재료 하나와 함께 소모된다. 유리는 산을 담는 용기로 사용할 수 있다.
- 소금이 물에 닿으면 소금물이 된다. 소금물을 가열하면 증기가 생기고 빈 이웃 셀에 소금이 남는다. 빈 이웃 셀이 없으면 공간이 생길 때까지 증발을 보류한다.
- 식물은 인접한 물을 낮은 확률로 식물로 바꾸며 자란다.

압력·바람·공기 유동·정확한 화학량론·실제 회로 해석은 포함하지 않는다. 온도·반응 임계값은 게임 규칙이다. 고밀도 장면은 진행 속도가 낮아질 수 있다.

## 저장

소스 실행 시 `user_data/sandbox/scene.json`, 설치본은 기존 앱 사용자 데이터 폴더 아래 `sandbox/scene.json`을 사용한다. 저장 버튼은 기존 슬롯을 덮어쓴다. 저장하지 않은 장면은 도구 전환 시 사라진다.

임시 파일에 쓴 뒤 교체하며, 읽을 때 버전·파일 크기·격자 크기·재료·온도·수명을 검증한다. 잘못된 파일은 현재 장면을 유지하고 오류를 표시한다. 복원 후에는 정지 상태로 시작한다.
