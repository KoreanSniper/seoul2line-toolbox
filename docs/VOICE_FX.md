# TTS · Voice FX 사용 및 검증 안내

## 주요 구현 위치

| 위치 | 역할 |
| --- | --- |
| `app/services/voice_fx.py` | 효과 설정 검증·순서별 DSP·출력 보정·캐시 |
| `app/services/voice_fx_store.py` | 공유 사용자 프리셋·현재 설정·원자적 저장 |
| `app/services/tts.py` | 기존 Windows TTS 확장·원본 보존·재사용·변조 연결 |
| `app/tools/file_tts.py`, `app/tools/voice_fx_editor.py` | TTS 탭·효과 편집·미리듣기·진행/취소 |
| `app/services/voice_fx_soundboard.py`, `app/tools/voice_fx_soundboard.py` | 원본을 보존하는 사운드보드 일괄 변조 복사 |
| `app/services/voice_fx_probe.py`, `app/healthcheck.py`, `installer/build.ps1` | 네이티브 의존성 수집·동결 실행·설치 프로그램 검사 |

## 사용 방법

1. **파일 → TTS 음성 생성 → 텍스트·음성·출력**에서 텍스트와 Windows 음성, 읽기 속도, 볼륨을 선택합니다.
2. **목소리 변조·프리셋**에서 기본 프리셋을 선택하거나 **음성 변조 활성화**를 켜고 개별 효과를 체크합니다. 각 효과 이름을 누르면 조절값이 펼쳐지고 ↑/↓로 적용 순서를 바꿉니다. 피치·배속·포먼트도 순서를 바꿀 수 있습니다.
3. 미리듣기와 일회용 출력은 첫 탭의 **출력/미리듣기 장치**를 먼저 선택합니다. CABLE Input을 선택하면 해당 가상 케이블로 출력합니다. 자동으로 다른 장치에 재생하지 않습니다.
4. **원본 미리듣기 / 변조 미리듣기**로 비교합니다. 기본은 원본의 앞 12초에 효과를 적용하며 잔향이 추가될 수 있습니다. 체크를 해제하면 전체를 비교합니다.
5. **WAV 저장 / 사운드보드 추가 / 일회용 출력**은 전체 음성을 사용합니다. 설정을 변경한 뒤 **변조만 다시 생성**을 누르면 보존한 직전 TTS 원본에 현재 체인만 적용합니다. 이어서 같은 설정으로 저장·출력하면 캐시를 재사용합니다.

텍스트·Windows 음성·읽기 속도·볼륨이 같으면 원본 TTS를 다시 합성하지 않습니다. 이 네 값이 바뀌면 새 원본을 생성합니다. 효과 설정이나 탭을 바꾸어도 입력 텍스트는 유지됩니다. 텍스트에는 스크롤과 글자 수 표시를 제공하며 Windows 음성 추가 후 **음성 새로고침**으로 목록을 갱신할 수 있습니다.

**처리 취소 / 정지**는 합성·변조·재생에 취소를 전달합니다. Python 처리와 블록 기반 효과는 중간에 취소를 확인하고, 네이티브 피치/배속 연산은 해당 단계 반환 후 취소를 확인합니다. 취소 결과를 확인한 뒤 새 작업을 시작할 수 있습니다. 중복 요청은 쌓이지 않으며 슬라이더 이동 자체로 렌더를 실행하지 않습니다.

## 효과와 프리셋

피치(-12~+12반음)는 길이를 유지하고, 재생 속도(0.5~2배)는 음높이를 유지합니다. Windows의 **TTS 읽기 속도(-10~10)**와 효과 체인의 **재생 속도**는 별도로 적용합니다. 포먼트(-6~+6반음 상당)는 켑스트럼으로 추정한 스펙트럼 포락선을 이동하며 배음 주파수와 위상을 보존하는 근사 방식입니다.

에코, 리버브, 디스토션, 비트크러시, 코러스, 링 변조 로봇, 라디오/무전기 대역 필터, 떨림(트레몰로: 음량 주기 변화), 역재생, 컴프레서, 리미터, 3대역 EQ를 조합할 수 있습니다. 각 효과를 개별 활성화하고 표시된 범위에서 조절합니다. 효과는 화면의 위에서 아래로 처리하므로 순서에 따라 결과가 달라집니다. 에코·리버브는 무음 구간을 추가해 잔향을 보존하고 끝부분을 짧게 페이드합니다. 최종 출력은 피크와 RMS를 보정하며 자동으로 원본보다 피크를 높이지 않습니다.

기본 프리셋은 원본·헬륨·저음·로봇·라디오·동굴·괴물·유령·전화기 9종이며 **사용자 정의**로 원하는 체인을 만들 수 있습니다. 프리셋을 고른 후 값을 바꾸면 **사용자 정의·수정됨**을 표시합니다. 기본 프리셋은 보호하며 초기화하면 모든 변조를 끈 원본 설정으로 돌아갑니다.

**사용자 프리셋 관리**를 펼쳐 새로 저장·선택 덮어쓰기·이름 변경·복제·삭제·JSON 가져오기/내보내기를 사용합니다. 이름은 1~60자, 사용자 프리셋은 최대 100개입니다. 프리셋에는 버전·식별자·이름·효과 순서·활성화 상태·전체 파라미터를 저장합니다. 가져온 프리셋은 새 식별자를 부여하며 같은 이름은 구분합니다. 손상되었거나 지원하지 않는 버전/효과/수치는 거부하고 기존 파일을 보존합니다.

## 사운드보드 연결

TTS의 **사운드보드 추가**는 전체 변조 WAV를 기존 관리 파일로 복사하여 등록합니다. 등록이 실패하면 새 항목과 미완료 파일을 정리합니다.

**게임 → 사운드보드 → 개인설정 → 목소리 변조 복사**에서는 기존 사운드를 하나 또는 여러 개 선택하고 같은 공유 프리셋 편집기를 사용할 수 있습니다. Ctrl/Shift로 다중 선택한 뒤 **선택 항목 변조 복사**를 누릅니다. 원본 항목과 파일을 유지하고 `[FX]` 제목의 새 WAV 항목을 등록하므로 원본 버튼으로 바로 돌아갈 수 있습니다. 이 기능은 등록된 WAV·MP3·OGG를 디코딩하며, 결과는 호환성을 위해 WAV로 등록합니다. 일괄 처리 도중 실패하거나 창을 닫아 취소하면 이번 작업에서 만든 항목만 모두 롤백합니다.

등록된 출력 파일은 렌더 결과를 보관하는 방식입니다. 사운드보드 재생 시점에 효과를 실시간 변경하거나 프리셋 수정이 기존 복사본에 자동 반영되는 기능은 포함하지 않습니다. 바뀐 설정은 새 변조 복사로 적용합니다.

## 저장·캐시·의존성

기존 사용자 데이터 경로 아래 `voice_fx/presets.json`에 사용자 프리셋, `voice_fx/current.json`에 마지막 효과 설정을 저장합니다. 앱을 다시 열어도 현재 설정을 복원합니다. 설치본은 기존 `%LOCALAPPDATA%/seoul2line Toolbox/user_data` 정책을 따릅니다. 프리셋은 업데이트 시 배포 파일로 덮어쓰지 않습니다.

원본 TTS는 도구 세션의 임시 폴더에 보존하며 종료 시 정리합니다. `voice_fx/cache`에는 원본 파일 SHA-256·전체 체인·순서·활성화·엔진 버전·샘플레이트·채널·미리듣기 길이로 식별한 WAV를 저장합니다. 캐시 한도는 WAV 합계 256MiB, 미사용 기간 30일이며 접근 시 오래된 결과부터 정리합니다. 출력 파일 해시·프레임·형식을 확인해 손상된 결과는 다시 생성합니다. 강제 프로세스 종료 시 세션 임시 파일이 남을 수 있습니다.

음성은 8~192kHz 모노/스테레오, 원본/결과 각각 최대 10분 또는 채널 합계 3,200만 샘플까지 처리합니다. 큰 파일은 텍스트를 나누세요. 추가 패키지는 `pedalboard==0.9.22`이며, 기존 NumPy·SoundFile을 재사용합니다. Pedalboard는 독립 피치·배속과 공간/다이내믹 효과를 CPU에서 처리하며 외부 서버·GPU·유료 API가 필요 없습니다. 선택 이유와 API는 [공식 Pedalboard 문서](https://spotify.github.io/pedalboard/reference/pedalboard.html)를 참고하세요.

배포 스크립트와 PyInstaller spec에 Pedalboard 및 네이티브 모듈 수집을 추가했습니다. 동결 실행 검사에는 기본 프리셋 9종 렌더·프리셋 왕복·TTS 화면 진입과 종료가 포함됩니다. 작업 실패의 상세 진단은 사용자 데이터 `logs/voice_fx.log`에 최대 1MiB씩 3개까지 기록합니다. TTS 입력 텍스트와 프리셋 내용은 로그 메시지에 기록하지 않습니다.

## 검증 및 한계

```powershell
py -m unittest discover -s tests -p "test_voice_fx*.py" -v
py -m unittest discover -s tests -p "test_tts.py" -v
py -m unittest discover -s tests -p "test_soundboard*.py" -v
powershell -NoProfile -File installer/build.ps1
```

자동 검사는 주파수·길이·신호 상한·포먼트 공명 이동·각 효과와 순서·잔향·모노/스테레오·다양한 샘플레이트·캐시 재사용/손상/만료·취소·기존 파일 보존·프리셋 재시작·세 테마 UI 응답과 사운드보드 등록을 확인합니다. 실제 한국어 TTS 파일로 모든 기본 프리셋 렌더도 검사했습니다. 자동 신호 검사는 사람이 느끼는 자연스러움을 보증하지 않으므로 청취 품질은 별도 확인이 필요합니다.

수동 확인: 스피커를 낮은 볼륨으로 선택해 같은 문장의 원본/헬륨/저음/괴물과 동굴/유령 잔향을 비교하고 파열음·치찰음·문장 시작과 끝의 잘림·클릭을 확인합니다. 다음으로 CABLE Input을 선택해 다른 앱에서 가상 케이블 입력을 확인하고, 처리/재생 중 취소와 장치 연결 해제 후 복구를 확인합니다. 프리셋 저장 후 앱 재실행·설치본에서도 같은 체인과 순서가 복원되는지 확인합니다.

포먼트는 켑스트럼 기반 근사 구현으로 고음·속삭임·극단적인 설정에서 자연스러움이 떨어질 수 있습니다. 기본 프리셋 수치는 신호 안정성과 렌더 검사를 거쳤으며, 사용자 음성별 청취 튜닝이 남아 있습니다. 보코더·음높이 비브라토·실시간 사운드보드 효과 할당은 포함하지 않습니다. 떨림은 음량 트레몰로, 로봇은 링 변조를 제공합니다.
