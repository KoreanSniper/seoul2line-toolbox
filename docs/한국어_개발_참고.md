# Tkinter와 Toolbox 기능 참고

이 문서는 이 프로젝트에서 자주 사용하는 Tkinter 함수와 Toolbox 전용 구조를 빠르게 확인하기 위한 메모입니다.

## Tkinter 기본 구조

### `Tk`

애플리케이션의 최상위 창입니다.

```python
root = tk.Tk()
root.title("도구 이름")
root.mainloop()
```

- `title()`: 창 제목을 설정합니다.
- `geometry()`: 창의 초기 크기를 설정합니다.
- `minsize()`: 창을 줄일 수 있는 최소 크기를 설정합니다.
- `mainloop()`: 버튼 클릭, 키보드, 타이머 같은 이벤트를 계속 처리합니다.

### `Frame`

위젯을 묶는 컨테이너입니다. 화면을 헤더, 본문, 버튼 영역처럼 나눌 때 사용합니다.

```python
panel = tk.Frame(parent, bg="#20252b")
panel.pack(fill="both", expand=True)
```

### 자주 쓰는 위젯

- `Label`: 글자나 상태를 표시합니다.
- `Button`: 클릭 시 `command` 함수를 실행합니다.
- `Entry`: 한 줄 입력을 받습니다.
- `Text`: 여러 줄의 로그나 문서를 표시합니다.
- `Canvas`: 도형, 그래프, 진행 표시 등을 직접 그립니다.
- `Checkbutton`: 켜짐/꺼짐 선택을 표시합니다.
- `Toplevel`: 별도의 보조 창을 만듭니다.

## 배치 함수

### `pack()`

위젯을 위, 아래, 왼쪽, 오른쪽 순서로 배치합니다. 간단한 세로·가로 목록에 적합합니다.

```python
label.pack(side="left", padx=8)
```

- `fill="x"`, `fill="both"`: 남은 공간을 채웁니다.
- `expand=True`: 부모가 커질 때 위젯도 함께 커집니다.
- `padx`, `pady`: 바깥 여백입니다.

### `grid()`

행과 열로 배치합니다. 입력 폼이나 표 형식 UI에 적합합니다.

```python
frame.columnconfigure(1, weight=1)
entry.grid(row=0, column=1, sticky="ew")
```

- `row`, `column`: 위치입니다.
- `sticky="nsew"`: 네 방향으로 늘어납니다.
- `rowconfigure()`와 `columnconfigure()`: 남은 공간의 가중치를 지정합니다.

### `place()`

정확한 좌표나 비율로 배치합니다. 일반 화면보다 Canvas 위의 특수 배치에 주로 사용합니다.

## 값과 이벤트

### `StringVar`, `IntVar`, `BooleanVar`

Tkinter 위젯과 Python 값을 연결하는 변수 객체입니다.

```python
status = tk.StringVar(value="대기")
tk.Label(parent, textvariable=status).pack()
status.set("완료")
```

- `get()`: 현재 값을 읽습니다.
- `set(value)`: 값을 바꾸고 연결된 위젯을 갱신합니다.

### `configure()`

이미 만들어진 위젯의 속성을 바꿉니다.

```python
label.configure(text="새 상태", fg="green")
```

### `bind()`

마우스나 키보드 이벤트에 함수를 연결합니다.

```python
entry.bind("<Return>", lambda _event: run_command())
```

이벤트 함수는 보통 `event` 인자를 하나 받습니다.

### `after()`와 `after_cancel()`

Tkinter 이벤트 루프에 나중에 실행할 함수를 등록합니다. 반복 갱신, 지연 실행, 스레드 결과 전달에 사용합니다.

```python
job = root.after(1000, refresh)
root.after_cancel(job)
```

백그라운드 스레드에서 위젯을 직접 변경하지 말고 `after(0, callback)`으로 메인 Tkinter 스레드에 전달해야 합니다.

### `destroy()`와 `winfo_exists()`

- `destroy()`: 위젯과 자식 위젯을 제거합니다.
- `winfo_exists()`: 위젯 명령이 아직 존재하는지 확인합니다.

화면 전환이나 창 닫기와 함께 실행되는 타이머·스레드 콜백은 위젯이 이미 삭제되었을 수 있으므로 확인이 필요합니다.

## 이 프로젝트의 Toolbox 구조

### `ToolSpec`

도구의 ID, 표시 이름, 메뉴 분류, 화면 생성 함수를 등록하는 자료 구조입니다.

```python
registry.register(ToolSpec("developer.example", "예제", "개발자", build, 50))
```

### `build(parent, app)`

Toolbox가 도구 화면을 만들 때 호출하는 진입 함수입니다. 반환한 Frame이 작업 영역에 표시됩니다.

```python
def build(parent: tk.Widget, app: object) -> tk.Widget:
    return ExampleTool(parent, app)
```

### `register(registry)`

도구를 메뉴에 등록하는 함수입니다. 파일에 `register()`가 있어야 Toolbox가 해당 도구를 찾을 수 있습니다.

### `palette(app.dark_mode)`

현재 테마에 맞는 배경색, 글자색, 테두리색 등을 반환합니다. 직접 색상을 반복해서 쓰기보다 이 팔레트를 사용하면 다크·라이트 모드가 함께 유지됩니다.

### `RoundedButton`, `RoundedFrame`

프로젝트의 공통 버튼과 패널 위젯입니다. 일반 Tkinter 위젯처럼 부모, 텍스트, 콜백을 전달해 사용합니다.

### `app.config_store`

간단한 설정을 저장하는 프로젝트 공통 객체입니다.

```python
value = app.config_store.get("group", "key", default="")
app.config_store.set("group", "key", value=value)
```

주식 데이터처럼 구조가 크거나 갱신이 잦은 데이터는 SQLite 같은 전용 저장소를 사용합니다.

## 스레드와 UI 갱신 규칙

1. 오래 걸리는 계산, 파일 작업, 프로세스 실행은 `threading.Thread`에서 처리합니다.
2. 작업 결과를 Tkinter 위젯에 표시할 때는 `self.after(0, callback)`을 사용합니다.
3. 화면이 닫힐 때 `Event.set()`으로 작업 루프를 멈춥니다.
4. 콜백 안에서는 `self._destroyed` 또는 `winfo_exists()`를 확인합니다.
5. 위젯을 만든 스레드가 아닌 곳에서 `configure()`, `insert()`, `delete()`를 직접 호출하지 않습니다.

## 자주 쓰는 기능 요약

| 기능 | 주로 쓰는 함수 | 용도 |
| --- | --- | --- |
| 상태 표시 | `StringVar`, `configure` | 작업 진행·결과 표시 |
| 버튼 동작 | `Button`, `command` | 함수 실행 |
| 반복 갱신 | `after`, `after_cancel` | 타이머와 폴링 |
| 화면 전환 | `destroy`, `build` | 현재 도구 교체 |
| 파일 선택 | `filedialog` | 파일 열기·저장 |
| 알림창 | `messagebox` | 오류·확인·완료 안내 |
| 백그라운드 작업 | `threading.Thread` | UI 멈춤 방지 |
| 로컬 데이터 | `sqlite3`, `config_store` | 저장·불러오기 |
