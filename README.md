# seoul2line Toolbox

Windows용 Python 데스크톱 도구함입니다. Tkinter 기반의 한 화면 안에서 게임 실행, 개발 작업, 파일 관리, 네트워크 확인, 미니게임과 샌드박스를 함께 제공합니다.

[기능 목록](#기능-목록) · [설치 및 실행](#설치-및-실행) · [자동화 안내](docs/AUTOMATION.md)

## 빠른 시작

### 요구 사항

- Windows
- Python 3.11 이상 권장
- `tkinter`가 포함된 Python 설치

### 설치 및 실행

```powershell
py -m pip install -r requirements.txt
py main.py
```

또는 Windows 탐색기에서 `run.bat`을 실행합니다.

## 사운드보드

**재생 대기 (초)**에 0~3,600초를 입력하면 버튼 클릭 후 지정 시간만큼 기다렸다 재생합니다. 소수 입력도 가능하며 0초는 즉시 재생입니다. 대기 중 남은 시간을 표시하며, 같은 버튼을 다시 누르거나 전체 정지·개인설정 전환·화면 종료 시 예약을 취소합니다. 다른 사운드를 누르면 이전 재생·예약을 취소하고 새로 대기합니다. 대기 시간은 현재 화면에서만 유지합니다.

**게임 → 사운드보드 → 개인설정**에서 사운드를 추가하고 버튼을 눌러 MP3·WAV·OGG 파일을 선택합니다. 제목은 Enter 또는 포커스 이동 시 저장하며, 화살표와 드래그 손잡이로 순서를 바꿀 수 있습니다. 개인설정을 종료하면 버튼 클릭으로 재생하고 같은 버튼을 다시 누르면 정지합니다. 다른 버튼을 누르면 기존 재생을 먼저 종료합니다. 도구를 닫거나 테마를 변경해도 재생을 정지합니다.

출력 장치는 개인설정에서 **1~2개를 직접 선택**합니다. Windows 장치 ID와 장치별 볼륨을 저장하며, 선택했던 장치가 연결 해제되어도 다른 장치로 자동 전환하지 않습니다. 전체 볼륨과 장치별 볼륨은 일반 모드에서도 조절할 수 있고 곱하여 적용됩니다. 전체 정지는 두 출력에 모두 적용됩니다.

SoundCard 0.4.5의 WASAPI 공유 모드로 장치별 독립 스트림을 열고 시작 신호를 공유합니다. 각 장치의 샘플레이트·채널 변환은 Windows 오디오 엔진이 처리합니다. 물리·가상 장치의 버퍼와 하드웨어 시계가 달라 완전한 동기화는 보장하지 않습니다. SoundFile 0.13.1과 포함된 libsndfile로 파일을 스트리밍 디코딩합니다.

파일은 기존 사용자 데이터 경로의 `soundboard/<UUID>.<확장자>`로 복사하며, `soundboard/soundboard.db`에 제목·상대 경로·순서·시각·볼륨·출력 장치 ID를 저장합니다. 설치본의 사용자 데이터 경로는 `%LOCALAPPDATA%\seoul2line Toolbox\user_data`, 소스 실행은 프로젝트의 `user_data`입니다. 원본 파일을 옮겨도 재생됩니다. 파일 전체 검증과 DB 저장이 실패하면 새 복사본을 제거하고, 교체·삭제 시 DB에서 더 이상 참조하지 않는 관리 파일만 정리합니다. 기존 DB는 변경하지 않습니다.

자동 검사는 `py -m unittest discover -s tests -p "test_soundboard*.py" -v`로 실행합니다. 물리 출력과 VB-Audio 출력 조합의 실제 스트림 검사는 PowerShell에서 `$env:RUN_SOUNDBOARD_DEVICES='1'`을 지정한 뒤 `test_soundboard_devices.py`를 실행합니다. 짧고 낮은 볼륨의 테스트 음원을 출력하며, 청취 품질·장치 간 지연·물리 연결 해제 검사는 별도 수동 확인이 필요합니다.

오디오 파일 등록 중 도구를 닫으면 복사·디코딩 작업을 취소하고 미완료 복사본을 제거합니다. 등록 완료 안내를 확인한 뒤 화면을 이동하세요.

## TTS 음성 생성

**파일 → TTS 음성 생성**에서 텍스트를 입력하고 음성·속도(-10~10)·볼륨(0~100)을 선택한 뒤 **WAV 저장**을 누릅니다. Windows에 설치된 SAPI 음성을 사용하며 한국어 음성이 있으면 우선 선택합니다. 인터넷이나 API 키는 필요하지 않으며 최대 10,000자를 처리합니다. 사용할 음성이 없으면 Windows 설정에서 음성을 설치한 뒤 도구를 다시 여세요. 설치된 음성 종류는 PC마다 다릅니다.

생성 중에도 화면이 응답하며, 화면 종료 시 작업을 취소합니다. 생성·WAV 검증에 성공한 뒤 최종 경로로 교체하므로 실패 시 기존 파일을 보존합니다. 저장한 WAV는 사운드보드의 개인설정에서 등록해 사용할 수 있습니다. Windows PowerShell과 .NET System.Speech를 사용하며 엔진 응답 제한은 180초입니다. 음성 엔진 API는 [Microsoft 문서](https://learn.microsoft.com/en-us/dotnet/api/system.speech.synthesis.speechsynthesizer?view=netframework-4.8.1)를 참고하세요.

**사운드보드에 추가**를 누르면 별도 파일 선택 없이 생성한 음성을 사운드보드에 등록합니다. 사운드 제목이 비어 있으면 입력 텍스트의 첫 줄(최대 100자)을 사용합니다. 등록 후 **게임 → 사운드보드**로 이동해 재생할 수 있습니다. 생성·등록 실패나 취소 시 새 항목과 임시 파일을 정리합니다.

**일회용 출력 장치**에서 케이블의 재생 장치(예: **CABLE Input**)를 선택하고 **일회용 출력 (재생 후 폐기)**을 누르면 생성한 음성을 해당 장치로 한 번 출력합니다. 선택한 음성·속도·볼륨을 적용하며 저장 경로 선택이나 사운드보드 등록은 필요하지 않습니다. 정상 재생 종료·오류·화면 종료 시 재생 스트림을 닫은 뒤 임시 WAV와 임시 폴더를 제거합니다. 장치 목록은 **새로고침**으로 다시 조회하며, 선택했던 장치가 사라지면 다른 장치로 자동 출력하지 않습니다. 프로세스 강제 종료나 전원 차단 시에는 임시 파일이 남을 수 있습니다.

TTS 검사는 `py -m unittest discover -s tests -p "test_tts.py" -v`로 실행합니다. 이번 요청의 최종 변경 후 추가 실행 검증은 사용자 요청에 따라 생략했습니다.

## 에임 연습

게임 메뉴의 **에임 연습**에서 마우스 DPI, 기준 게임 메모, 게임의 회전 계수(감도 1일 때 입력 1카운트당 회전각), 수평 FOV를 입력합니다. 마우스 자체 DPI 설정은 마우스 소프트웨어에서 맞춰야 합니다. 게임 이름은 메모이며 프리셋을 자동 적용하지 않습니다. 기본 회전 계수 0.07은 사용자 정의값입니다.

실제 eDPI는 **800으로 고정**되고 감도는 `800 / DPI`입니다. 예를 들어 DPI 800이면 감도 1.0, DPI 1600이면 감도 0.5입니다. Windows Raw Input의 상대 이동 카운트에 감도와 입력한 회전 계수를 곱해 시점을 회전시킵니다. 커서 속도·가속 설정을 감도 계산에 사용하지 않습니다. 360° 회전 거리는 `360 × 2.54 / (회전 계수 × 800)` cm입니다.

3D 사격장의 바닥·벽·천장과 구 표적은 XYZ 좌표에서 카메라 기저로 변환한 뒤 시야 절두체로 잘라 원근 투영합니다. 표적 크기는 픽셀이 아닌 미터 단위 반지름이며, 거리에 따라 화면 크기가 달라집니다. **마우스**로 시점을 회전하고 **WASD**로 이동하며, **좌클릭** 발사는 카메라 중심 광선과 표적 구의 교차로 판정합니다. 방 경계 밖으로는 이동하지 못합니다. Tk Canvas에서 메시를 그리는 CPU 렌더러이며 특정 게임 엔진의 그래픽·물리 전체를 재현하지는 않습니다.

연습 시간·표적 크기를 정하고 시작하면 명중률과 표적 생성 후 적중까지 평균 시간이 표시됩니다. 원시 입력은 Tk와 별개의 Windows 메시지 스레드에서 수집하며, 전경 창이 아닐 때의 패킷은 저장하지 않습니다. 조작 갱신과 렌더링은 별도 타이머를 사용하고 이동은 경과 시간에 따라 120Hz 단계로 처리합니다. 이는 목표 단계 주기이며 실제 갱신률은 기기 부하에 따라 달라집니다. **F3**로 렌더 FPS·실제 조작 갱신률·최대 갱신 간격·입력 대기 시간을 확인할 수 있습니다.

**Esc**, 화면 이탈, 도구 전환 또는 창 크기 변경 시 연습을 끝내고 커서 고정·입력 스레드·두 타이머를 정리합니다. 기록은 세션 동안만 유지됩니다. 절대 좌표만 제공하는 원격 데스크톱·태블릿 입력은 지원하지 않습니다.

## Windows 설치 파일 만들기

일반 사용자는 [최신 설치 프로그램](https://github.com/KoreanSniper/seoul2line-toolbox/releases/latest)에서 EXE를 받으면 됩니다. Python 설치는 필요하지 않습니다. `update_installer.bat`도 최신 정식 릴리스를 받아 SHA-256·크기를 검증한 뒤 설치 화면을 엽니다.

소스에서 빌드하려면 Python 3.11 이상과 Inno Setup 6을 설치하고 다음 명령을 실행합니다. `release/seoul2line-toolbox-setup.exe`와 검증용 `release/update.json`이 생성됩니다.

```powershell
powershell -ExecutionPolicy Bypass -File installer\build.ps1 -InstallDependencies
# 또는 update_installer.bat --build
```

버전은 `app/version.py`의 `VERSION`에서 관리합니다. 해당 버전과 같은 `v2.0.1` 형식의 태그를 push하면 GitHub Actions가 빌드하고 실행 파일의 화면·메뉴·기본 플러그인 로딩을 검사한 뒤 설치 EXE와 `update.json`을 정식 Release에 게시합니다. Actions에서 수동 실행하면 배포 전 검토용 artifact만 생성됩니다.

설치본은 시작 시와 실행 중 6시간마다 새 버전을 백그라운드에서 확인합니다. 설치 확인을 누르면 다운로드·체크섬 검증 후 앱을 종료하고 같은 폴더에 업데이트한 뒤 다시 실행합니다. 설정에서 자동 확인을 끄거나 수동으로 확인할 수 있습니다. 소스 실행에서는 설치본으로 자동 교체하지 않습니다.

**설정 → 업데이트 → 이전 버전 선택**에서 현재보다 낮은 정식 버전을 선택할 수 있습니다. 설치 EXE와 검증용 `update.json`이 있는 릴리즈만 표시하며, 경고에 동의한 뒤 버전·크기·SHA-256을 검증해 설치합니다. 다운그레이드하면 설정·게임 저장·자동화 기록 등 데이터가 사라지거나 손상될 수 있으므로 사용자 데이터 폴더를 먼저 별도로 백업하세요. 소스 실행에서는 선택한 버전의 다운로드 페이지를 엽니다. 자동 업데이트 확인이 켜져 있으면 최신 버전을 다시 안내합니다.

설치본의 사용자 설정·게임 저장·사용자 플러그인·업데이트 로그는 `%LOCALAPPDATA%\seoul2line Toolbox\user_data`에 보관되므로 앱을 덮어써도 유지됩니다. 기존 설치 폴더의 `user_data`는 최초 실행 시 기존 파일을 덮어쓰지 않고 복사합니다. 소스 실행은 프로젝트의 `user_data`를 사용합니다. 업데이트 실패 로그는 사용자 데이터의 `updates/install-update.log`에서 확인할 수 있습니다.

처음 실행하면 `user_data` 폴더와 설정 파일이 생성될 수 있습니다. 외부 프로그램 실행·파일 삭제·네트워크 기능은 사용자가 입력한 경로와 권한의 영향을 받습니다.

### 자동화

기본 제공 `automation_tools` 플러그인(자동화 도구)에서 제공합니다. 설정 → 플러그인에서 메뉴를 켜고 끌 수 있으며 저장된 워크플로와 실행 기록은 유지됩니다. 메뉴를 꺼도 실행 중인 자동화는 계속 동작합니다.

| 도구 | 주요 기능 |
| --- | --- |
| 워크플로 편집기 | 노드 배치·연결, 간편·고급 모드, 조건 분기, 데이터 자동 전달, 검증·테스트 실행·저장 |
| 자동화 관리 | 저장한 워크플로 관리, 파일 감시 활성화·비활성화 |
| 자동화 실행 기록 | 워크플로 실행 결과·오류 로그 확인 |

파일 감시 → 조건 → 이미지 변환 → 파일 이동 등을 연결할 수 있습니다. 감시는 앱 실행 중에 동작하며, 사용 예제는 [자동화 안내](docs/AUTOMATION.md)를 참고하세요.

## 공통 사용법

- `Ctrl+K`: 상단 중앙 통합 검색창으로 이동 (↑/↓ 선택, Enter 실행, Esc 닫기)
- 왼쪽 메뉴: 섹션과 도구 전환
- 다크/라이트/그린 테마: 설정 → 테마 및 화면에서 팔레트를 고른 뒤 `저장`으로 적용
- 보조 탐색: 기본은 펼친 상태입니다. 왼쪽 아래 `도구 목록 펼치기` / `도구 목록 접기`로 전환하거나 목록 제목 옆 `‹`로 접을 수 있으며, 조절한 너비를 복원합니다.
- 지갑: 미니게임에서 사용하는 툴코인 잔액 표시

도구 화면은 선택된 순간 생성됩니다. 따라서 사용하지 않는 도구의 갱신 루프가 계속 CPU를 사용하는 것을 피할 수 있습니다. 단, 한국 주식 가격 엔진은 앱 전체에서 공유되며 한국 주식 화면의 가격 갱신 버튼으로 시작·중지합니다.

## 데이터 저장

| 경로 | 내용 |
| --- | --- |
| `user_data/config.json` | 테마, 단축키, 실행 경로, 지갑, 공장 자동화 등 일반 설정 |
| `user_data/stocks.db` | 한국 주식 가격, history, 보유 수량, 평균 매입가, 거래 이력 |
| `user_data/` | 캡처·수신 파일 등 사용자 생성 데이터 |

주식 데이터는 SQLite로 저장됩니다. 가격 엔진은 SQLite WAL과 busy timeout을 사용하며, 저장 실패가 발생하면 재시도 후 화면 상태에 오류를 표시합니다. `config.json`의 기존 한국 주식 데이터는 최초 마이그레이션 이후 `stocks.db`로 이동합니다.

사용자 데이터를 초기화하거나 백업하기 전에는 앱을 종료해 진행 중인 저장 작업이 끝났는지 확인하세요. `config.json`과 `stocks.db`는 함께 백업해야 지갑과 주식 상태를 같은 시점으로 복원할 수 있습니다.

### 새 도구 추가

`app/tools/example.py`를 만들고 `register()`에서 `ToolSpec`을 등록합니다.

```python
import tkinter as tk
from app.tool_registry import ToolSpec


def build(parent: tk.Widget, app: object) -> tk.Widget:
    frame = tk.Frame(parent)
    tk.Label(frame, text="내 도구").pack()
    return frame


def register(registry) -> None:
    registry.register(ToolSpec(
        "developer.example",
        "내 도구",
        "개발자",
        build,
        50,
    ))
```

도구에서 백그라운드 작업을 사용할 때는 Tkinter 위젯을 작업 스레드에서 직접 변경하지 말고 `after()`를 이용해 UI 스레드에서 반영합니다. 종료 시 스레드와 `after()` 작업을 취소하고, 파일·프로세스·네트워크 입력은 실패 가능한 작업으로 취급해야 합니다.

### 외부 플러그인 추가

설정의 `ZIP 파일 선택하기` 버튼으로 플러그인 ZIP을 고르고 안전 경고를 확인하면 `user_data/plugins/plugin_<id>/`에 압축을 해제하고 바로 불러옵니다. `plugin.json`은 ZIP 최상위 또는 바로 아래 플러그인 폴더에 있어야 합니다. 기존 플러그인은 덮어쓰지 않습니다.

외부 확장은 `plugins/` 또는 사용자별 `user_data/plugins/` 아래에 폴더 단위로 추가합니다. 폴더에는 `plugin.json`과 `plugin.py`가 필요하며, `plugin.py`의 `register(registry)`에서 `SectionSpec`으로 왼쪽 최상위 메뉴를, `ToolSpec`으로 도구를, `MenuSpec`으로 메뉴 액션을 등록합니다. `SectionSpec`은 `Home`, `Game`, `Developer`처럼 사이드바에 표시되는 카테고리입니다. `MenuSpec`은 섹션 왼쪽 목록과 `Ctrl+K` 커맨드 팔레트에 표시됩니다. 앱 설정 화면의 `플러그인 다시 검색`으로 즉시 반영할 수 있습니다. 비활성화된 플러그인과 로딩 오류는 설정 화면에서 상태를 확인할 수 있습니다.

플러그인은 앱 프로세스 안에서 실행되므로 신뢰할 수 있는 코드만 설치해야 합니다. 전체 형식과 예제는 `plugins/README.md`를 참고하세요.

## 검증

현재 저장소에는 전체 자동화 테스트 스위트가 아직 없습니다. 변경 후 최소한 다음을 실행합니다.

```powershell
py -m py_compile app\main_window.py app\config.py app\tools\minigame_korean_stocks.py
```

GUI 변경은 실제 창에서 메뉴 전환, 빠른 시작·중지, 앱 종료, 창 크기 변경까지 확인해야 합니다. 주식 도구는 매수·매도, 시장 초기화, SQLite 저장 실패, DB 잠금, 상승장·하락장·횡보장을 함께 확인합니다.

## 문제 해결

- `ModuleNotFoundError`: `py -m pip install -r requirements.txt`를 다시 실행합니다.
- Tkinter 창이 열리지 않음: tkinter가 포함된 Python 설치를 사용하고 Windows 디스플레이 세션에서 실행합니다.
- 주식 가격이 갱신되지 않음: 상단 가격 갱신 버튼 상태와 주식 도구의 오류 메시지를 확인합니다.
- 설정이 초기화됨: 앱 종료 후 `user_data/config.json`의 백업을 확인합니다.
- 주식 상태가 이상함: 앱을 종료한 뒤 `user_data/stocks.db`를 백업하고, 복구가 필요하면 TODO의 DB 검증·백업 절차를 먼저 진행합니다.
