# seoul2line Toolbox Mobile — 기획 v0.1

앱 표시명 S2 Toolbox, Android, Python + Kivy. 기존 Windows Toolbox는 독립 유지한다.
처음에는 APK를 직접 배포하며 Buildozer를 검토한다. Play Store 배포는 후속 검토다.

## 화면 원칙

상단 왼쪽 로고는 홈으로 이동하고 오른쪽 검색은 전체 도구를 검색한다.
상단 가운데에는 별도 요소를 넣지 않는다. 선택 도구는 가운데 콘텐츠 영역에 표시한다.
하단은 사용 빈도 메뉴 1위 / 메뉴 2위 / 고정 홈 / 도구 1위 / 고정 설정 순서다.
추천 슬롯을 길게 눌러 고정·해제하며 재시작 후에도 유지한다. 메뉴 중복은 허용하지 않는다.
테마와 기존 사용자 제공 로고를 유지하며 Tkinter UI는 Kivy로 다시 구현한다.

## PC 연결 및 TC

Cloudflare Workers + Durable Objects를 중심으로 기기 인증·권한 확인·암호화 통신을 구성한다.
CPU/RAM/GPU 상태 조회, PC 게임 실행 요청, 워크플로 실행·중지, 양방향 파일 전송·채팅,
자동 재연결·오류 처리를 제공한다. 실제 연결 전에는 상태나 명령 성공을 임의로 표시하지 않는다.

TC는 서버 데이터를 기준으로 PC·모바일에 같은 잔액을 제공한다.
거래를 서버에서 원자적으로 처리하고 거래 ID·변경 내역을 보관하며 중복 요청을 검증한다.
오프라인 잔액은 조회 캐시만 제공하고 사용자 인증과 거래 요청 검증을 적용한다.
PC `config.json`을 단순 양방향 복사하는 방식은 사용하지 않는다.

## 개발 순서

1. Kivy 기본 UI: 로고·홈·검색·하단 탭·테마. Android 실제 실행 확인.
2. 기본 도구: TTS·사운드보드·개발자 변환기·메모.
3. 네트워크: Cloudflare 연결·채팅·파일 전송.
4. PC 연동: 시스템 모니터·게임 실행·자동화 관리.
5. 고급 도구: Minecraft Toolkit·GitHub·파일 변환.
6. 경제·미니게임: 한국 주식·공장 자동화·TC 동기화.
7. APK 빌드·Android 테스트·오류 수정·직접 배포.
